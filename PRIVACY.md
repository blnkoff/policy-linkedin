# Privacy Policy — Personal LinkedIn Inbox Exporter

**Effective date:** October 20, 2026

## 1. About this application

Personal LinkedIn Inbox Exporter is a personal-use application intended to let its developer access, export, and organize their own LinkedIn data through the official LinkedIn Member Data Portability API, including message history where permitted by LinkedIn.

This application is not affiliated with, endorsed by, or operated by LinkedIn Corporation.

## 2. Information accessed

With the LinkedIn account holder's authorization, the application may access:

- LinkedIn messages and conversation metadata (including message text, timestamps, and participant names or identifiers);
- other account information included in the data portability response, only where needed for the requested export; and
- OAuth access tokens needed to authenticate API requests.

Message history can include information about other people participating in conversations. That information is used only as part of the account holder's personal archive.

## 3. How information is used

Data is used solely to export, store, search, and organize the authorized account holder's LinkedIn history for their personal use. The application does not use the data for advertising, marketing, profiling other users, or selling personal information.

## 4. Storage and sharing

The application is intended to run locally on the account holder's device. Exported messages and authentication credentials are not intentionally sent to an application-operated server. The application does not sell or share exported data with advertisers, data brokers, or other third parties.

Requests to LinkedIn are made through LinkedIn's official API, subject to LinkedIn's own terms and privacy practices. The account holder is responsible for protecting any locally exported files.

## 5. Data retention and deletion

Exported data is retained locally until the account holder deletes the exported files or application storage. The account holder may revoke the application's access through LinkedIn's account settings. Revoking access does not automatically delete copies already exported to the local device; those copies must be deleted separately.

## 6. Security

The application is designed to use LinkedIn's authorization flow rather than request the user's LinkedIn password. Authentication tokens and exported data should be stored securely on the account holder's device and must not be committed to a public GitHub repository.

## 7. Children's privacy

The application is not designed for use by children and does not intentionally collect children's information.
